# KASI-LINK 🇿🇦
### From Kasi To The World

Book verified South African talent - DJs, artists, dancers & performers from Chatsworth to every stage.

**Stack:** React + Vite + Tailwind + YouTube (no API key)
**Status:** Building MVP

### 🔥 What is Kasi-Link?
Platform to link kasi talent to paid bookings. No more DM scams. Verified artists, direct WhatsApp bookings.

### ✨ Features
- 🎤 Artist profiles with YouTube videos
- 📅 Direct booking via WhatsApp
- ✅ Verified kasi talent
- 💸 No commission (MVP)

### 🛠️ Run Locally
npm install
npm run dev
